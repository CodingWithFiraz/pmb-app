========================================================================
CARA MENJALANKAN WEBSITE PMB (PENGGUNAAN HARIAN)
========================================================================

1. Buka Terminal 1 (di dalam folder pmb-app):
   npm run dev

2. Buka Terminal 2 (di dalam folder pmb-app):
   php artisan serve --port=8001

3. Buka browser:
   http://localhost:8001


========================================================================
⚠️ PERINGATAN PENTING TENTANG DATABASE (BACA INI!)
========================================================================

JANGAN PERNAH menjalankan perintah ini saat membuka aplikasi:
❌ php artisan migrate:fresh --seed   <-- INI AKAN MENGHAPUS SEMUA DATA!

Perintah `migrate:fresh` berfungsi untuk DROP (MENGHAPUS BERSIH) seluruh 
tabel database beserta akun pendaftar dan formulir yang sudah tersimpan.

Jika Anda menjalankan `migrate:fresh` setiap hari, maka:
- Semua akun pendaftar yang sudah dibuat akan terhapus.
- Semua data formulir dan berkas yang sudah diinput akan hilang.
- Database kembali bersih seperti saat pertama kali dibuat.

Gunakan perintah database berikut sesuai kebutuhan:
- Untuk update struktur migrasi baru tanpa menghapus data:
  php artisan migrate

- HANYA gunakan `migrate:fresh --seed` jika Anda MEMANG SENGAJA ingin
  mereset total database ke kondisi awal demo/pabrik.

=======================================================================
KONFIGURASI MIDTRANS (PEMBAYARAN SNAP)
=======================================================================
Isi kredensial sandbox Midtrans pada file .env:

MIDTRANS_SERVER_KEY=...        # Server Key dari dashboard Midtrans
MIDTRANS_CLIENT_KEY=...        # Client Key (opsional)
MIDTRANS_IS_PRODUCTION=false   # true saat sudah produksi

Alur pembayaran:
1. Admin memverifikasi pendaftar -> tagihan otomatis dibuat (UKT, dan
   biaya pendaftaran untuk jalur Mandiri).
2. Pendaftar membayar lewat /pendaftar/pembayaran (Midtrans Snap).
3. Midtrans memanggil callback POST /midtrans/callback -> status tagihan
   terupdate menjadi Lunas / Kedaluwarsa / Gagal.
4. Tombol "Unggah Bukti" tersedia sebagai cara manual jika tidak bisa
   memakai Midtrans; bukti menunggu peninjauan panitia.

Tanpa MIDTRANS_SERVER_KEY, tombol Snap akan menampilkan pesan bahwa
konfigurasi Midtrans belum lengkap (uji otomatis tetap jalan memakai
mock gateway pada tests/Feature/PembayaranMidtransTest.php).

=======================================================================
FASE 10 — PENGUMUMAN, KARTU PESERTA, DAN POLISH
=======================================================================
Fitur baru:
- Admin /admin/pengumuman: set hasil kelulusan (lulus/tidak_lulus/belum)
  per pendaftar atau bulk via checkbox, dengan filter periode/jalur/status.
- Admin /admin/pembayaran/verifikasi: verifikasi pembayaran manual
  (paid/failed) dengan bukti transfer.
- Pendaftar /pendaftar/pengumuman: lihat hasil kelulusan.
- Pendaftar /pendaftar/kartu: kartu peserta dengan barcode, hanya jika
  lulus dan semua tagihan lunas. Bisa dicetak (Ctrl+P).
- Notifikasi di dashboard pendaftar saat hasil kelulusan dikeluarkan.
- Kebijakan akses (Policy): pendaftar hanya bisa akses data milik sendiri.
